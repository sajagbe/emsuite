# Internal documentation

This directory contains engineering records that are useful to maintainers and
automation agents but are not part of the public Zensical site.

- `ENGINEERING.md` and `ROADMAP.md` describe internal direction.
- `SESSION_*.md` contains historical handoff and changelog records.
- `plans/` contains implementation plans and progress notes.
- `session_records/` contains reproducibility manifests.
- `legacy-sphinx/` preserves the documentation source used before the Zensical
  migration, including its nested `combined/`, `potential/`, and `tuning/`
  sections.

The public documentation source is in [`../docs/`](../docs/).
